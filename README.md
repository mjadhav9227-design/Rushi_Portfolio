# ASR Motion Studio

An editable React + Vite copy of the ASR Motion Studio portfolio website, prepared to open in Visual Studio Code and run with npm.

## Open and run

1. Extract `ASR-Motion-Studio-VSCode.zip`.
2. In VS Code, choose **File → Open Folder** and select the extracted `asr-motion-studio-vscode` folder.
3. Make sure Node.js is installed, then open the VS Code terminal in this folder.
4. Install dependencies once with `npm install`.
5. Start the development server with `npm run dev`.
6. Open the local address printed in the terminal.

You can edit the page in `src/App.tsx`, its styles in `src/index.css`, and its page metadata in `index.html`. The visual-study images are in `public/`. Run `npm run build` to create a production build.

The portfolio examples are explicitly labeled as concept studies because completed client projects were not provided.
